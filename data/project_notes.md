# Developer Productivity MCP

This demo server is a Module 14 learning assignment for the Model Context Protocol.

## Purpose

Expose a small set of developer-productivity capabilities through the official MCP Python SDK.

## Tools

- `add_task` — create a local development task.
- `list_tasks` — list tasks by status.
- `complete_task` — mark a task as done.
- `search_project_notes` — search project notes.
- `calculate` — safely evaluate basic arithmetic.

## Resource

- `project://overview` — this project overview.
- `task://{task_id}` — a task as structured JSON.

## Prompt

- `code_review` — generate a reusable code-review prompt.

## Host integration

This server is designed for local stdio integration with Claude Desktop, Claude Code, Cursor, or another MCP host.
